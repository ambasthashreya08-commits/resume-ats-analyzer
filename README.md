# Resume ATS Analyzer

A Python application that analyzes resumes against job descriptions and provides an ATS compatibility score.

## Features

- Resume parsing
- Keyword extraction
- ATS score calculation
- Match percentage generation

## Tech Stack

Python, PyPDF2

## Workflow

1. Upload resume PDF
2. Extract resume text
3. Compare against job description keywords
4. Calculate ATS score
5. Display matching skills
