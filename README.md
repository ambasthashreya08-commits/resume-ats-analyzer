# 🚀 Overview

Resume ATS Analyzer is a Streamlit-based application that evaluates resumes against job descriptions and provides an ATS compatibility score.

The system helps job seekers identify missing skills and optimize resumes before applying.

---

# ✨ Features

| Feature | Description |
|----------|-------------|
| 📄 Resume Upload | Upload PDF resumes |
| 💼 Job Description Analysis | Compare against target role |
| 🎯 ATS Score | Calculate compatibility score |
| 🔍 Keyword Matching | Detect missing keywords |
| 📊 Match Percentage | Quantify resume relevance |
| ⚡ Instant Analysis | Real-time results |

# ⚙️ Run Application

Install dependencies:

```bash
pip install -r requirements.txt
```

Start:

```bash
streamlit run app.py
```

Application runs at:

```text
http://localhost:8501
```
